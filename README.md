# Virtual Fashion Stylist Web Application

## Overview
An AI-based web application that provides personalized outfit recommendations based on user preferences, body type, and occasion.

## Features
- User authentication
- Body type analysis
- Personalized outfit recommendations
- Wardrobe management
- Feedback system for improving suggestions

## Technologies Used
- Backend: Python (Django)
- Frontend: React
- Machine Learning: Basic ML models
- APIs: Weather and fashion trends APIs
